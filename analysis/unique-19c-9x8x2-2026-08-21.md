# Unique 19-cell 9+8+2 thermometer Sudoku

The deterministic guided search found a unique classic Sudoku constrained by
three cell-disjoint king-neighbour thermometers of lengths 9, 8, and 2. The
thermometers cover exactly 19 distinct cells. Cells below use one-based
`RrCc` notation, from bulb to tip:

```text
R1C3-R1C4-R2C4-R2C3-R3C2-R4C1-R5C1-R4C2-R5C2
R6C8-R7C8-R7C9-R8C8-R9C7-R9C6-R9C5-R8C6
R2C8-R3C7
```

The unique solution is:

```text
831274569
964358271
257961843
682743195
793125486
415896327
578612934
126439758
349587612
```

Along the three thermometers the solution values are respectively `1..9`,
`2..9`, and `7,8`.

## Discovery run

The first one-cell-only run exhausted its deterministic frontier after 8,188
base evaluations without improving the known exact count of four. A fresh run
with `--two-cell-reroutes` enabled reached the unique layout as a one-cell child
of the reroute-expanded trajectory:

- round 57, base evaluation 15,251;
- clean `status=unique` exit after 1,928.490030 seconds;
- 611 beam evaluations, 5,514 one-cell mutations, and 9,126 two-cell reroutes;
- 67,449 proof-safe solution pairs and 59,640 distinct pair cuts in the final
  seed checkpoint.

The search itself is heuristic and non-exhaustive. This does not qualify an
absence result, but the uniqueness classification of the construction is
exact.

## Independent verification

All checks used the paths above rather than trusting the guided-search score:

- the generic Rust solver exhausted the search at count 1 and returned the
  displayed solution;
- Interactive Sudoku Solver at revision
  `c43bfb867baa0f9c12c087afe912d626ac13a77a` returned 1 from
  `countSolutions(2)`;
- retained native builds of dclamage/SudokuSolver at revisions
  `5b3f1a69f915153e3251568e1b4c64119a393e3d` and
  `b588ea4c6b58` both returned 1 from single-threaded
  `CountSolutions(maxSolutions: 2)`;
- Rangsk's 1.3.188 console release independently returned count 1; and
- a separate exhaustive Python DFS using only classic row/column/box masks and
  the adjacent strict inequalities returned the same sole grid after 80,918
  search nodes.

Geometry was also checked independently: every path is simple, all 19 cells
are distinct across paths, and every consecutive pair is king-adjacent.
